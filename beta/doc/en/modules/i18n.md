# `ps5m/i18n.py`

One language = one `langs/xx.json` file. Adding a language needs no code.

## API

| Function | Role |
|---|---|
| `codes()` | available codes, English first |
| `available()` | `[{code, name, english, direction}]` for the UI |
| `load(code)` | activate a language (English fallback if missing) |
| `current()` / `direction()` | active language, writing direction |
| `tr(key, **fmt)` | translate, format `{placeholders}` |
| `coverage(code)` | `(translated, total, missing keys)` |

## Format

```json
{
  "_meta": {"name": "Français", "english": "French", "direction": "ltr"},
  "app.title": "PS5 Fedora Manager",
  "status.missing": "Missing"
}
```

`_meta` is never shown as a string: `available()` reads it. A missing key falls
back to English, then to the raw key, so a missing translation can never crash
the app.

## Adding a language

1. `cp beta/langs/en.json beta/langs/ja.json`
2. Translate the values, set `_meta.name` ("日本語") and `_meta.english`.
3. `python3 beta/tools/lang_status.py --missing ja` for the key list.
4. Restart the app: the language appears in the selector.
