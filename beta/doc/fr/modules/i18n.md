# `ps5m/i18n.py`

Une langue = un fichier `langs/xx.json`. Aucun code à modifier pour en ajouter.

## API

| Fonction | Rôle |
|---|---|
| `codes()` | codes présents, anglais d'abord |
| `available()` | `[{code, name, english, direction}]` pour l'interface |
| `load(code)` | active une langue (repli anglais si absente) |
| `current()` / `direction()` | langue active, sens d'écriture |
| `tr(key, **fmt)` | traduit, formate `{placeholders}` |
| `coverage(code)` | `(traduites, total, clés absentes)` |

## Format

```json
{
  "_meta": {"name": "Français", "english": "French", "direction": "ltr"},
  "app.title": "PS5 Fedora Manager",
  "status.missing": "Absent"
}
```

`_meta` n'est jamais affiché comme une chaîne : il est lu par `available()`.
Une clé absente retombe sur l'anglais, puis sur la clé brute : l'application ne
plante jamais à cause d'une traduction manquante.

## Ajouter une langue

1. `cp beta/langs/en.json beta/langs/ja.json`
2. Traduire les valeurs, renseigner `_meta.name` (« 日本語 ») et `_meta.english`.
3. `python3 beta/tools/lang_status.py --missing ja` pour la liste des clés.
4. Relancer l'application : la langue apparaît dans le sélecteur.
